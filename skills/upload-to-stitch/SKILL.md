# upload-to-stitch

## Description
A skill for uploading design data and screen information to the Stitch MCP server.

## Commands
### Upload Design MD
Upload a DESIGN.md file to the Stitch MCP server.

### Edit Screen
Edit an existing screen on the Stitch MCP server.

## Tags
- stitch
- mcp
- upload

## Output Schema
The output schema includes resolvable `$defs` for all screen instance types. All schema references resolve within the schema itself.
